# Weather Release Provenance & Availability Contract (V2.1)

## 1. Source Semantics (`open-meteo-previous-runs` / `ecmwf_ifs025`)

- **Endpoint**: `https://previous-runs-api.open-meteo.com/v1/forecast`
- **Model Parameter**: `models=ecmwf_ifs025`
- **Hourly Field Suffix**: `_previous_day2` (queries forecast values valid at target hour `t` from the model run initialized two calendar days earlier, i.e., `run_initialization_utc = forecast_valid_time_utc - 48h`).
- **Archive Start Date (Empirically Verified)**: Live API probing established `ecmwf_ifs025` `_previous_day2` returns `null` for `2023-06-01` and `2024-01-15`, and becomes populated from `2024-04-01` through `2025-12-31`. Consequently, matched weather studies restrict analysis strictly to `flight_date >= 2024-04-01` rather than imputing unarchived `2023` weather.

## 2. Proven Metadata vs Engineering Assumptions

| Metadata Element | Status | Value / Rule | Notes |
|---|---|---|---|
| `forecast_valid_time_utc` | **Proven (API payload)** | Exact ISO GMT timestamp from `hourly.time` | Joined within `<= 30` min of `scheduled_departure_utc` (origin) or scheduled arrival UTC (dest) |
| `checksum` | **Proven (Computed)** | SHA256 of canonical sorted JSON payload | Stored per airport request in `data/manifests/weather_v2_manifest.json` |
| `retrieved_at_utc` | **Proven (Logged)** | UTC timestamp at ingestion | Audited at fetch time |
| `run_initialization_utc` | **Contractual (`_previous_day2`)** | `valid_utc - timedelta(days=2)` | Encodes Open-Meteo `previous_dayN` archived lead semantics |
| `model_availability_time_utc` | **Domain Assumption (Explicit)** | `run_initialization_utc + 6h` = `T - 42h` | Open-Meteo JSON does not publish cycle dissemination timestamps; assuming a 6h ECMWF IFS dissemination lag leaves an 18h safety buffer before the `T-24h` prediction cutoff |

## 3. Production Honesty & Fallback Guarantee

- The default serving bundle (`models/flight_delay_v2_1_bundle.joblib`) remains **flight-only** (`100%` airport coverage, zero external weather dependency).
- Any optional/experimental `F5` weather bundle (`src/flight_delay/models/predictor.py`) enforces `model_availability_time_utc <= prediction_at_utc` and degrades gracefully (`NaN` numeric weather + `*_weather_missing=1` + `weather_status="degraded_fallback_missing_weather"`) on API timeout, HTTP 429/5xx, or missing coordinates (`tests/test_weather_serving_fallback.py`).
