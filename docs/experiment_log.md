# Experiment Log

## Version 1 Benchmark

- Target: BTS `DepDel15`.
- Decision time: T-24h.
- Population: valid binary label, not cancelled, not diverted.
- Data: nine official BTS Reporting Carrier monthly archives from 2023-2025.
- Sampling: deterministic monthly cap defined by `prepare_dataset.py`.
- Selection: validation PR-AUC.
- Calibration: Platt logistic mapping on the dedicated October 2024 partition.
- Threshold: maximum F1 on the calibration partition.
- Locked test: January and July 2025, evaluated only after model selection.
- Weather: not evaluated because a uniform issued-run archive is unavailable for
  the full benchmark window.

Exact runtime, row counts and metrics are generated by the executed pipeline and
stored under `reports/`.
